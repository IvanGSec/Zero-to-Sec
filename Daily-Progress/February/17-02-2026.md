# LOOPS (BUCLES)

-Un bucle es una estructura que permite repetir un bloque de codigo varias veces.En Bash existen 3 tipos principales:

  * for
  * while
  * until

-Cada uno sirve para un caso distinto,pero todos comparten la misma idea de repetir acciones.
-A continuacion una breve explicacion del loop for :  (( Mas adelante entrare en detalle de while y until ))


  * for : Es el mas sencillo para recorrer listas o rangos de numeros.Ejemplo:

            
#!/bin/bash           *Aqui se definiria el interprete.En este caso Bash.
                        
for i in {1..10}      * {} genera la lista 1 2 3 4 ... 10
do                    * "do" comienza el bucle                                  
    echo "$i"         * Esto imprime el valor actual,en este caso "$i"
done                  * "done" termina el bucle



  * Otro ejemplo para destriparlo mejor:

1. for VARIABLE in LISTA
2. do
3.   COMANDOS
4. done

*FILA 1: ( for VARIABLE in LISTA ):

- VARIABLE → un nombre que tú eliges (como i,num,archivo,etc.)
- LISTA → los valores que quieres recorrer uno por uno

*FILA 2: ( do ):

- Aquí empieza el bloque de código que se repetirá.
- Piensa en " do " como " A partir de auqi,ejecuta esto en cada vuelta del bucle "

*FILA 3: ( COMANDOS ):

- Aqui pones lo que quieres repetir.Por ejemplo " echo $i "

*FILA 4: ( done ):

- Significa " Aqui termina el bloque del bucle.Vuelve arriba y pasa el siguiente valor "


# CONDITIONAL STATEMENTS

-Un condicional es una estructura que permite que mi script tome decisiones.
-En castellano seria:

" Si pasa X,hago esto.Si no pasa,hago otra cosa "

-Es lo mismo que hacemos en la vida real.Por ejemplo:

 * Si llueve,llevo paraguas
 * Si tengo hambre,como
 * Si el archivo existe,lo abro

-En Bash,esto se hace con if , then, else, elif y fi .

-Pero que hacen exactamente los condicionales? Evaluan una condicion (Algo que puede ser verdadero o falso).Y dependiendo del 
resultado,ejecutan un bloque u otro.Para que sirven en mi script?:

  * Para que mi script compruebe si un archivo existe.
  * Para que mi script verifique permisos.
  * Para que mi script compare numeros y cadenas.
  * Para que mi script tome decisiones segun la salida de un comando.
  * Para que mi script controle errores.
  * Para que mi script valide entradas del usuario.

-Sin condicionales,un script solo ejecutaria cosas en orden.Con condicionales,mi script piensa y elige.Ejemplo basico:

if [ condición ]
then
    comandos_si_verdadero
fi
